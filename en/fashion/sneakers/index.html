Sneakers: the right price in a flash

Sneakers are one of the purchases where the gap between store and online prices shows the most. With the right code you compare exactly the same model and colourway.

The right code for sneakers

  1. Box: scan the barcode on the side label.
  2. No box: open the tongue, there is a label with the style code (e.g. Nike CW2288-111). Use “Read the label”.
  3. Colour: the last digits of the code are the colourway, so you don't compare a different version.
