Zapatillas: el precio justo al instante

Las zapatillas son de las compras donde más se nota la diferencia entre tienda y online. Con el código correcto comparas exactamente el mismo modelo y color.

El código correcto

  1. Caja: enfoca el código de barras de la etiqueta lateral.
  2. Sin caja: abre la lengüeta, hay una etiqueta con el código de modelo (p. ej. Nike CW2288-111). Usa “Leer la etiqueta”.
  3. Color: las últimas cifras indican el color, así no comparas otra versión.
