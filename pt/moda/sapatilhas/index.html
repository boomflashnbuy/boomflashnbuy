Sapatilhas: o preço certo num instante

As sapatilhas são das compras onde mais se nota a diferença entre loja e online. Com o código certo comparas exatamente o mesmo modelo e a mesma cor.

O código certo

  1. Caixa: aponta para o código de barras da etiqueta lateral.
  2. Sem caixa: abre a lingueta, há uma etiqueta com o código do modelo (ex. Nike CW2288-111). Usa “Ler a etiqueta”.
  3. Cor: os últimos dígitos indicam a cor, assim não comparas outra versão.
