# BoomFlashnBuy (Boom Flash'n'Buy)

**Sei in negozio? Scansiona il codice a barre e scopri in 1 secondo se su Amazon costa meno.**
Web app gratuita, funziona dal browser, senza installare niente.

👉 **Apri l'app: [boomflashnbuy.netlify.app](https://boomflashnbuy.netlify.app)**

- 📷 Inquadra il codice a barre (o il codice modello) in negozio
- ⚡ Vedi subito le offerte Amazon dello stesso prodotto
- 🎙️ Oppure scrivi o di' cosa cerchi
- 📱 iPhone: "Ehi Siri, boom" · Android: un tocco dalla Home
