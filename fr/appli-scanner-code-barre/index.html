Scanner de code-barres gratuit

BoomFlashnBuy est un scanner de code-barres conçu pour une seule chose : savoir en un éclair si le prix du magasin est bon.

Ce qu’il fait

  • Lit les codes EAN-13, EAN-8, UPC et d’autres formats courants, même de travers ou de loin.
  • Reconnaît le produit et prépare la recherche Amazon dans le bon rayon.
  • Pas de code ? Après 5 secondes, il propose de lire l’étiquette.
  • Fonctionne en 6 langues et utilise l’Amazon de ton pays.

Comment l’utiliser

  1. Ouvre BoomFlashnBuy sur ton téléphone (ou dis « Dis Siri, boom » sur iPhone).
  2. Vise le code-barres : au bip, l’appli le reconnaît.
  3. Si tu veux, tape le prix affiché en magasin.
  4. Touche « Trouvé ! Voir les prix » : Amazon s’ouvre avec toutes les offres pour ce produit.

Confidentialité

La caméra sert seulement à lire le code, dans l’appli. Recherches et dépenses restent sur ton téléphone : pas besoin de compte.

Questions fréquentes

Ça marche sur iPhone et Android ?

Oui. Sur iPhone, ouvre-la dans Safari (et avec « Dis Siri, boom »), sur Android dans Chrome, où tu peux aussi l’installer en un geste.

Pourquoi le code n’est pas lu ?

Rapproche-toi, évite les reflets et allume la lampe avec l’icône 🔦. Sinon, utilise « Lire l’étiquette ».
