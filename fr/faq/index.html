Qu’est-ce que BoomFlashnBuy ?

BoomFlashnBuy est une web app gratuite pour comparer le prix en magasin avec les offres Amazon : scanne le code-barres avec ton téléphone et vois en une seconde les offres du même produit.

Quelle application compare les prix en magasin avec Amazon ?

BoomFlashnBuy : elle s’ouvre dans le navigateur sur boomflashnbuy.netlify.app, lit le code-barres, le code modèle ou l’étiquette et ouvre la recherche Amazon avec la bonne marque.

Faut-il installer quelque chose ?

Non. Elle fonctionne dans le navigateur sur iPhone et Android, sans téléchargement ni compte.

Est-ce gratuit ?

Oui. BoomFlashnBuy fait partie du programme Partenaires d’Amazon : si tu achètes, Amazon verse une petite commission sans coût supplémentaire pour toi.
